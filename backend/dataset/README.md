# dataset

Fotos para entrenar, **una carpeta por clase**: `organica/` (0), `inorganica/` (1), `peligroso/` (2).
`_por_verificar/<clase>/` guarda etiquetas aportadas por usuarios hasta que el operador las apruebe.

Las fotos de las 3 clases **sí están en git** (unos 20 MB) para que cualquiera que clone el repo pueda jugar la práctica con fotos. Las de `_por_verificar/` no se suben (ver `.gitignore`). Origen y licencia: `docs/recursos_externos.md` (The Garbage Dataset).
