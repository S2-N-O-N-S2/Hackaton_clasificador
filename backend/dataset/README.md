# dataset

Fotos para entrenar, **una carpeta por clase**: `organica/` (0), `inorganica/` (1), `peligroso/` (2).
`_por_verificar/<clase>/` guarda etiquetas aportadas por usuarios hasta que el operador las apruebe.

Las fotos **no se suben a git** (ver `.gitignore`); compártanlas por USB o unidad compartida.
