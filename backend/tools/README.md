# tools

Utilidades de apoyo: `verificar_hardware.py` (Fase 0) y `calibrar_angulos.py` (Fase 5).


Otras herramientas:
- `probar_camara.py`: toma fotos con el método del sistema y muestra brillo y nitidez, para ajustar los umbrales de `CAMARA` en `app/config.py`.
- `calibrar_desconocidos.py v1`: crea `models/v1/novedad.json` (detección de objetos desconocidos) sin reentrenar.
- `auditoria_usuarios.py`: auditoría con usuarios virtuales contra el backend en simulación (ver `docs/resultados/auditoria_3000.md`).
